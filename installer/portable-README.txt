cutemarkdown @VERSION@ - portable
=================================

A fast, minimal, native Markdown reader for Windows 10 and 11 (64-bit).

Run it
  Double-click cutemarkdown.exe, then drop a Markdown file on the window.
  Or drag a .md file onto cutemarkdown.exe. Or from a terminal:
      cutemarkdown.exe notes.md

Nothing to install. It is a single file with no extra runtimes needed, and it does not
touch the registry. Put it anywhere (a USB stick works fine). Delete the file to remove it.

Make it your default Markdown app (optional)
  Right-click any .md file -> Open with -> Choose another app -> More apps ->
  "Look for another app on this PC" -> pick cutemarkdown.exe -> tick "Always use this app".
  Prefer a proper install (Start Menu entry, Default apps list, uninstaller)? Use the
  cutemarkdown-@VERSION@-setup-x64.exe installer instead.
